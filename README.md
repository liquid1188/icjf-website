# International Catholic Jurists Forum — website prototype

Static rebuild of icjurist.org by Lickity Split. All text is carried over verbatim from the current site
(99 live pages, 535 news posts). Pages are generated by `python3 build.py` (run it after editing `_shell.html`, `assets/`, or `data/`).

- `_shell.html` — page template; `assets/site.css`, `assets/site.js` — styles and the front end
- `build.py` — writes `index.html` and `/<slug>/index.html` for every page and news post (same addresses as the old WordPress site), `sitemap.xml`, `robots.txt`, `404.html`, and redirects
- `site.json` — `origin`, `base` (`/icjf-website/` on the prototype, `/` at launch), `noindex` (set `false` at launch), `redirects`
- `data/index.json` — page and news index used by navigation and search
- `data/p/*.json` — one file per page
- `data/n/*.json` — news bodies and thumbnails, in chunks
- `data/hero.json` — homepage photography and the ICJF seal

Noindexed until launch (`noindex` in `site.json`).
